the reference card — all 27 instructions

Every instruction is exactly two bytes: the opcode, then the operand. The operand is an 8-bit value, address or port — or two register numbers packed into one byte, a<<4 | b. R0 is the accumulator: LDI, LOAD and IN all fill it, and MOV moves it where you want it. This table is generated from the engine, so it cannot drift from the machine.
