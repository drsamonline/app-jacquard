Jacquard

Automation with an honest machine under it: a fictional 8-bit CPU, the Weft-8, programmed in assembly. The clock, the calendar, the clipboard, the accelerometer and the notifier are memory-mapped peripherals — you read a register, you act on it.

  • 27 instructions, each exactly two bytes, little-endian, on a real 16-register machine
  • an assembler with labels, .str and .byte, and errors that name the line
  • run, step, and watch the registers, the four flags and scratch RAM change
  • a reference card that teaches registers, flags, the stack and memory-mapped I/O by use
  • no network, no account, no telemetry — the machine is on this device
Open Jacquard

A program that does not assemble is refused with the line and the reason, never run half-way. A runaway loop stops at the step limit and says so. A stack underflow is an error, not a crash.
